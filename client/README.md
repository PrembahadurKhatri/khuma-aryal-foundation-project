# Khuma Aryal Foundation — Client

This is the frontend half of a split client/server app. Full project documentation —
overview, installation, environment variables, deployment, and API reference — lives in the
[repo root README](../README.md).

Quick start:

```bash
npm install
npm run dev        # http://localhost:5173, proxies /api to VITE_API_TARGET
npm run build       # production build -> dist/
```
