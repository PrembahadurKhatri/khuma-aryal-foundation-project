# Image folders

Drop real photos into these folders using the file names already referenced
in `src/data/content.js`. Until a file exists, the site automatically shows a
soft placeholder (initials avatar for people, gradient card for photos), so
nothing breaks if an image is missing.

- `leaders/` — Founder, President, Past President, Secretary, Advisor(s), Patron/Spouse (shown on the Home page)
- `projects/` — Project cover photos
- `gallery/` — Gallery page photos

Recommended sizes: people photos ~ 400x400px (square), project/gallery photos ~ 1200x900px (4:3).
